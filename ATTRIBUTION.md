# Attribution

This repository accompanies the paper *P-tensors: a General Framework for Higher Order Message Passing in Subgraph Neural Networks* (Hands, Sun, and Kondor, AISTATS 2024). The authors of that paper are the authors of this code.

AI coding assistants were used as tools for implementation and integration. They are not co-authors of the paper or the software. The authors reviewed the result and are responsible for it.

Please cite the paper (see `README.md`) rather than attributing the code to an AI system.
